# Time-Lag-Aware Deep Reinforcement Learning for FJSP in PPVC Module Factories

Code, benchmark generator, and experiments for the paper

> **[Time-Lag-Aware Deep Reinforcement Learning for Flexible Job-Shop Scheduling in PPVC Module Factories](https://doi.org/10.48550/arXiv.2607.11725)**
> Ziheng Zhang and Wei Zhang. arXiv:2607.11725, 2026.
> *(Under review at IEEE Transactions on Industrial Informatics.)*

📄 **Read the paper:** <https://doi.org/10.48550/arXiv.2607.11725>

**If you use this paper, its benchmark data, or this code in your own work, please cite the paper**
([BibTeX below](#citation)).

We study **flexible job-shop scheduling with post-operation time-lags (FJSP-TL)** as it arises on the
factory floor of **Prefabricated Prefinished Volumetric Construction (PPVC)**: concrete curing,
watertightness ponding tests, and paint drying are long lags during which a module is blocked but its
station is free. We adapt a dual-attention DRL solver to this setting through three minimally invasive,
individually ablatable extensions, and release a benchmark grounded in the Singapore BCA PPVC guidebook.

- **Lag-aware FJSP-TL extensions** — lag-aware transition dynamics with an admissible lag-augmented
  reward bound; anticipatory lag feature channels; operation/station type embeddings with liveness
  masking (all flag-gated; see `params.py`, `fjsp_env_same_op_nums.py`, `model/`).
- **BCA-grounded PPVC benchmark generator** — `ppvc_instance_generator.py`.
- **Evaluation & analysis pipeline** — `eval_ppvc.py`, `eval_a0_repair.py`, `eval_reactive.py`,

  independent feasibility validator `schedule_validator.py`.

## Quick start

```bash
conda create -n fjsp python=3.11 && conda activate fjsp
pip install -r requirements-blackwell.txt        # torch, numpy, ortools, pandas, scipy, matplotlib

python ppvc_instance_generator.py                # generate a PPVC instance set
python train.py --data_source PPVC --n_j 10 \
       --use_lag_features True --use_type_embedding True     # train the full method (A3)
python eval_ppvc.py --model_name 10x25+ppvc-mixed+full \
       --data_path data/PPVC/10x25+ppvc-mixed                # evaluate (greedy + sampling)
python analyze_results.py                        # aggregate results into summary tables
```

## Reproducing the paper

Ablation arms (A0 lag-blind, A1 lag-aware dynamics, A2 `+`features, A3 full) are selected by the
`--ppvc_lagblind / --use_lag_features / --use_type_embedding` flags. The multi-seed, M-tight, and
reactive-rescheduling experiments are driven by `run_seed_campaign.sh`, `run_gpu_chain.sh`,
`run_cpsat_chain.sh`, and `run_reactive.sh`. Every reported number is regenerated by
`analyze_results.py`.
